# Triplet kinematic-grid pilot and exact conditional direction controls

## What is prepared

The runner builds the pinned QuirkPheno adapter once, then runs one-CPU cases
sequentially on the AF node. It does not submit Condor jobs. With eight seeds
it prepares 116 cases:

| Mode | Cases |
| --- | ---: |
| Isotropic forced-pion decays | 36 |
| CM-collinear forward pion control | 36 |
| CM-collinear backward pion control | 36 |
| Stable transport controls | 8 |

The four points are beta_each=0.4 at theta=90 degrees and B=2 T (existing
benchmark), beta=0.4 at theta=60 degrees and B=2 T, beta=0.6 at theta=90
degrees and B=2 T, and the original kinematics at B=0. All have production
CM boost beta_z=0.25, neutral mass 225 GeV and Lambda_tension=774 eV.
Seeds 1--8 run at level 8. Seed 1 and the stable controls also run at level 7.
The two refinement levels are numerical checks, not independent population
events. The same seeds across points are correlated; results are not pooled
as independent samples or weighted as an inclusive pp production sample.

## Control definition

The isotropic sample uses the existing independent exponential proper-time
thresholds and rest-frame isotropic pion directions. Both conditional controls
retain those thresholds, masses and the exact on-shell two-body decay. At
each vertex, the pion rest-frame direction is chosen parallel or antiparallel
to the instantaneous parent momentum in the fixed production CM. This removes
the transverse pion momentum in that CM while retaining longitudinal recoil.

The direction is transported through the canonical boosts into the lab-based
parent-rest convention used by the existing decay process. A massless probe
vector obtains the rest-frame Wigner rotation; the actual massive pion is
then generated by the unchanged two-body kinematics. For a parent at rest
in the production CM, the planned axis is the declared fallback. The test
checks both signs, nonparallel boosts and this degenerate-axis case.

This is an energy-conserving conditional decay-angle control. It is neither
a physical zero-recoil decay nor an isotropic event population. Its comparison
with isotropic events measures dependence on the transverse-kick component
under these conditions. It must not be described as an inclusive with/without-
recoil rate ratio. Stable cases remain separate transport controls.

The pilot forces the pion channel while using the total LO lifetime,
which is valid for the lifetime distribution conditional on that channel.
The frozen pion branching fraction is about 97.60% per endpoint; the roughly
4.73% of pairs with at least one non-pion channel are not simulated here.
Those modes can matter for rare tails and must be checked before an inclusive
physics claim. The kinematic grid is a pilot, not a PDF-weighted production
ensemble or a final statistical sample.

## Audit, censoring and compact handoff

The existing sampled-pion auditor now also reads output directories directly
and checks the conditional CM directions. It verifies full step counts,
last-row/event-time agreement, weak proper thresholds, four-momentum,
mass shells, daughter identity/charge, and preserved string handoffs.
The ROOT files remain on AF; a failed local audit stops packaging.

For each case, the packager searches 0.65--1.35 times the predicted first-return
time. It transforms positions to the production CM before estimating the
closest approach. A minimum at a search-window edge is rejected rather than
silently used. A narrow per-endpoint +/-0.5 ps lab window is exported around
that common-CM minimum. This search assumes the first return remains near
the radial estimate; unexpected earlier or additional minima require review.

All zero-, one- and two-decay categories at the estimated return are counted.
Only windows with both endpoints neutral, with neutral samples bracketing the
minimum, are qualified for the current neutral secular-capture model. Other
events stay in the manifest and the compact archive as censored categories.
The model driver retains these population summaries and reports paired seed
differences only conditional on both modes being neutral-qualified. It does
not infer inclusive survival from that subset.

The output archive contains the manifest, local audit, macros/cards/plans,
case logs, build/patch logs and compressed NPZ windows. It contains no ROOT
files or build directory. A `--pack-only` option repeats the local audit and
packaging without rerunning transport. Actual archive size and runtime have
not yet been measured on AF for this suite.

## Validation completed locally

* C++ direction controls compile with warnings as errors and preserve exact
  two-body four-momentum through the tested boosts and both control signs.
* Four ensemble tests cover plan pairing, boosted invariant masses, macro
  hashes, minimum-window edge censoring, conditional paired summaries, and
  synthetic exact CM-collinear decay records with corruption rejection.
* The previous sampled-pion synthetic audit passes through both archive and
  directory routes. All 20 prior real AF sampled-pion files pass the updated
  directory auditor.
* The default 116-case configuration prepares successfully, and the worker
  refactor and new runner pass Python compilation checks.

The new Geant4 process integration has **not** been compiled or executed
locally: this environment lacks the AF Geant4/CVMFS view. Native helper tests
are not a substitute for the first AF build/run. The runner checks the pinned
upstream preimages and patch before building, then stops on the first failed
case. No jobs have been submitted or run on AF by this implementation turn.

## Run on the AF node

Use a fresh output directory:

```bash
cd ~/QuirkSim
git pull --ff-only origin research/quirkpheno-weak-recoil-pilot
python scripts/af_triplet_recoil_ensemble.py \
  --output-dir /data/aalida/QuirkSim/triplet_ensemble_v1 --seeds 8
```

Requires numpy/scipy and uproot/awkward in the Python environment already
used for the previous AF audits, plus the same CVMFS Geant4 view. The default
per-case execution timeout is 120 seconds. Build and individual-case failures
retain their logs and manifest. The final line prints the compact archive to
upload. Keep all ROOT files on AF.

After the new archive passes inspection, the existing scripts can run the
window bounds and connected model with matched conditional controls:

```bash
python scripts/audit_quirkpheno_return_window.py triplet_ensemble_v1_audit.tar.gz \
  --output ensemble_window_bounds.json
python scripts/compare_repeated_encounters.py triplet_ensemble_v1_audit.tar.gz \
  --output ensemble_declared_capture_models.json
```
