## Implemented change

The independent characteristic prototype evolves moving endpoint labels,
massive endpoint momenta, laboratory positions and proper times, coupled
through two causal unit-ray histories. This is a different numerical
formulation from the finite-element NG action. The bulk has no artificial
interior point masses and the endpoint equations include string energy
and momentum flux. The first implementation has zero external field and
no weak decays. See the [derivation](CONFORMAL_BOUNDARY_DERIVATION.md).

The extremely small radial/rotating errors reflect special exact solution
families. The rotating ray directions are great-circle functions, matching
the chosen interpolation exactly. These errors do **not** estimate the
uncertainty of arbitrary transverse, magnetic or near-contact trajectories.
Likewise, unit characteristic interpolation enforces the conformal constraints;
their tiny residuals alone are not independent physical validation.

## Meaning of the radial crossing check

Crossings occur at approximately 220.03789114, 444.18019945,
668.32250776 and 892.46481607 ps. The reduced adapter deliberately
reverses the ideal radial string orientation there and records that
additional prescription. Endpoint identity, momentum and proper time
are continuous. The generic characteristic solver does not use this
adapter to bypass chart collapse. This is classical mathematical
continuation under an explicit symmetry assumption, not annihilation
or a validated general 3D contact boundary.

## Reproduction

```
python -m pip install -e '.[test]'
python -m pytest -q
python scripts/validate_conformal_boundary.py
```

In an uninstalled source snapshot, prefix the last two commands with
`PYTHONPATH=.` so subprocess-based existing CLI tests can import the package.
The full suite initially failed four subprocess import checks without
that environment; rerunning with the package import path supplied passed
all 112 tests. No existing solver implementation was modified.
