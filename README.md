# QuirkSim

Independent, public research project for electroweak quirk weak decays and macroscopic-string dynamics. This repository is not part of ATLAS and contains no ATLAS-internal code.

**Development:** initial solver, decay implementation, numerical tests and limitations are maintained on the `development/standalone-simulator` branch. The default branch remains a stable project landing page until the research prototype is validated.

**Physics scope:** Dirac electroweak doublet/triplet quirks, charged-to-neutral pion transitions, recoil, and string dynamics. No collider reach or annihilation predictions are currently certified.
